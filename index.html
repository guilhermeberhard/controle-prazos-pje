    Gerar resposta

    Importar do PJE

    No PJE, abra a lista de expedientes / intimações pendentes (ou o próprio documento), selecione o conteúdo com Ctrl+A, copie com Ctrl+C e cole abaixo. O sistema identifica automaticamente os números de processo, datas, prazos, vara e tipo de diligência.

    Baixe do PJE o PDF do despacho/ofício/intimação e arraste para cá (pode ser vários de uma vez). Cada PDF vira uma diligência. Funciona com PDFs que têm texto selecionável (os gerados pelo próprio PJE); documentos escaneados não são lidos.

    Instale uma única vez: arraste o botão abaixo para a barra de favoritos do navegador (Ctrl+Shift+B mostra a barra).

    ⇩ Enviar ao Controle de Prazos

    Depois, no PJE, abra a tela de expedientes (ou um documento) e clique no favorito. Esta tela abre sozinha com os dados prontos para conferência. Se quiser enviar só uma parte, selecione o trecho antes de clicar.

    O favorito apenas lê o que já está na sua tela do PJE e envia diretamente para esta janela, dentro do seu computador. Nenhum dado passa por servidor externo e sua senha/certificado não são acessados.
